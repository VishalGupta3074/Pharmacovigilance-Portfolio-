Pharmacovigilance Portfolio Project

A simulated pharmacovigilance case-processing project developed to demonstrate practical understanding of Individual Case Safety Report (ICSR) processing and drug safety data management.

Project Overview

This project includes a series of simulated pharmacovigilance cases covering different adverse events, seriousness criteria, reporting scenarios, and case-processing activities.

Key Activities

- ICSR case data entry and management
- MedDRA coding (LLT, PT and SOC)
- Seriousness and expectedness assessment
- WHO-UMC causality assessment
- Case narrative writing
- Case status and reporting timeline management
- Pharmacovigilance data visualization and dashboard development

Project Files

- "PV Case Database" (database/PV_Case_Database.xlsx) — Structured Excel database containing simulated ICSR case information and case-processing fields.
- "PV Case Narratives" (narratives/PV_Case_Narratives.docx) — Individual case narratives prepared from the simulated case data.
- "Interactive Pharmacovigilance Dashboard" (https://vishalgupta3074.github.io/Pharmacovigilance-Portfolio-/) — Interactive dashboard featuring visual summaries, charts, and filters for the simulated case series.

Disclaimer

This is a simulated educational portfolio project. All cases, patient information, reporter information, and other case details are fictional and are not based on real patient reports or confidential data.

Purpose

This project was created to demonstrate the practical application of pharmacovigilance concepts and familiarity with common case-processing activities in preparation for an entry-level pharmacovigilance role.
